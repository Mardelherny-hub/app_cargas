En `BillOfLadingEditForm::loadBillOfLadingData()` se asignan directamente los IDs persistidos a los tres campos, y `loadFormData()` carga todos los clientes activos (incluido el 589). Por lo tanto, **con el BL y la base actuales la pantalla debería mostrar MSC ARGENTINA como cargador y consignatario; no existe una causa demostrada en los datos de Stage para que aparezcan visualmente vacíos**. No adjudicarla a caché, sesión, componente Livewire, selección del registro ni al importador sin una reproducción específica.

Consulta realizada en la misma base **Stage `cargas`**, mediante PDO, transacción explícitamente READ ONLY y ROLLBACK final. Se verificaron las columnas con `SHOW COLUMNS FROM webservice_transactions`. No se invocó ningún servicio aduanero ni se modificaron datos.

Hay **90 transacciones** identificables como RegistrarTitEnvios por soap_action, request_xml, additional_metadata o webservice_config. De ellas, **una** contiene codTipEmbalaje en los campos de error/respuesta: **id 503**, status **error**, created_at **2026-10-14 19:41:50** (valor literal de la base, sin conversión horaria), environment **production**. Mensaje, omitiendo el identificador del BL: «RegistrarTitEnvios: BL [omitido], línea 1: falta codTipEmbalaje EDIFACT de 2 caracteres.».

El valor environment=production corresponde al registro almacenado **en Stage**; no implica acceso al servidor de producción. La búsqueda ampliada a cualquier operación devuelve **5** registros con codTipEmbalaje; solo el indicado cumple además el filtro RegistrarTitEnvios. No se atribuyen los otros cuatro a esa operación.

Consultas exactas de datos:

```sql
SELECT code, argentina_ws_code, unece_code
FROM packaging_types ORDER BY code;

SELECT COUNT(*) total FROM webservice_transactions
WHERE LOWER(CONCAT_WS(' ',soap_action,request_xml,additional_metadata,webservice_config))
      LIKE '%registrartitenvios%';

SELECT id,status,environment,created_at,error_message
FROM webservice_transactions
WHERE LOWER(CONCAT_WS(' ',soap_action,request_xml,additional_metadata,webservice_config))
      LIKE '%registrartitenvios%'
  AND LOWER(CONCAT_WS(' ',error_message,error_details,response_xml,validation_errors))
      LIKE '%codtipembalaje%'
ORDER BY id;

SELECT COUNT(*) total_any_method FROM webservice_transactions
WHERE LOWER(CONCAT_WS(' ',error_message,error_details,response_xml,validation_errors))
      LIKE '%codtipembalaje%';
```

**Dictamen:** existencia del error solicitado confirmada; catálogo de cuatro filas informado completo. Los códigos UNECE están vacíos, pero estas lecturas no demuestran por sí solas la causa exacta del error histórico. Sin correcciones, importaciones ni escrituras en Stage.
